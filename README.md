# 信仰游戏排行榜

AstrBot 群聊双积分排名插件，登神之路 + 觐见之梯双榜展示，支持弃誓/立誓系统、职业信仰体系、信仰专属随机文案、批量录入、全局白名单权限管控、群名片自动识别玩家。

## 功能特性

- **双积分体系** — 登神之路 + 觐见之梯，双榜独立排名
- **职业信仰** — 6 职业 x 16 具体信仰，角色定制体系
- **弃誓系统** — 弃誓标记永久保留，排行榜显示(弃誓者)，可配置弃誓文本
- **立誓/设置职业** — 信仰与职业独立管理，弃誓者可通过立誓重新确立信仰
- **储物空间** — 玩家道具库系统，道具名与等级分离（固定等级 SSS/SS/S/A/B/C），支持批量录入、赐予/收回/清除道具，查询按等级排序
- **赠送道具** — 玩家间道具赠送，发送方自动从群名片识别，直接扣除等待接收方接受/拒绝（每位接收方每天限接受一次）
- **群名片识别** — 查询/储物空间/赠送道具等指令自动从群名片识别玩家身份，过滤职业词精准匹配
- **玩家状态** — 自定义状态效果，持续指定天数，查询时显示剩余天数
- **批量录入** — 粘贴游戏结算文本自动解析，批量更新积分（支持正负分）
- **全局白名单** — 白名单一次添加，所有群生效，支持绑定具体信仰
- **信仰主题文案** — 16 信仰专属随机文案，诸神操作显示对应神明身份（如"【沉默】降下神赐"）
- **储物空间彩蛋** — 可配置概率触发趣味消息
- **自动备份** — 数据自动备份，可配置保留天数
- **指令可配** — 所有指令名可通过 WebUI 配置修改
- **查询冷却** — 防刷机制，可配置冷却时间
- **直接回复** — 指令回复不经过 AI 处理，固定格式输出
- **祷词触发** — 玩家每天第一次发送命中自己命途祷词的消息时，随机获得 -2 到 +2 觐见分变化（可配置群列表、可配置回复文案）
- **合并转发** — 天梯榜、觐见榜、储物空间默认使用合并转发卡片展示

## 职业与信仰

### 层级结构
- **命途**（6）：虚无、存在、文明、沉沦、混沌、生命
- **信仰**（16）：诞育、繁荣、死亡、污堕、腐朽、湮灭、秩序、真理、战争、混乱、痴愚、沉默、记忆、时间、欺诈、命运
- **具体职业**（96）：每个信仰 × 6 普通职业，系统自动映射到对应命途和普通职业

### 普通职业
战士 / 法师 / 牧师 / 刺客 / 猎人 / 歌者

## 群名片自动识别

部分指令通过发送者的群名片自动识别玩家身份，无需手动输入名字：

- **查询**：非诸神用户直接发送 `查询` 即可查询自己；诸神用户需指定玩家名
- **查询储物空间**：非诸神用户直接发送 `查询储物空间` 查自己；诸神用户可指定多个玩家批量查询
- **赠送道具**：发送方自动从群名片识别，格式变为 `赠送道具 <接收方名> <道具*数量>`

非诸神用户如指定其他玩家名，系统会提示"只能查询自己"。

### 名片解析规则

系统从群名片中提取所有非纯数字、非职业的词，逐个在数据库中匹配，返回第一个匹配到的玩家名。例如：
- `【命运】 织命师 蓬莱 1000 100` → 提取词：蓬莱 → 匹配数据库中的玩家名
- `【XX】 守墓人 张三 100 100` → 提取词：张三 → 匹配数据库中的玩家名

### 具体职业自动识别

名片中的具体职业（96个）会被自动识别并过滤，不会误匹配为玩家名。例如：
- `【湮灭】 烬灭者 蓬莱` → "烬灭者"是具体职业，被过滤；匹配"蓬莱"

## 白名单与权限

### 诸神权限
拥有白名单权限的用户可执行所有诸神指令。

### 白名单配置
可通过 WebUI 配置或指令管理：

```
白名单 add <QQ> [信仰]    — 添加诸神，可选绑定信仰
白名单 remove <QQ>        — 移除诸神
白名单 setfaith <QQ> <信仰> — 修改信仰
白名单 removefaith <QQ>   — 移除信仰标记
白名单 view               — 查看诸神列表
```

有信仰的诸神执行操作时，会显示对应神明的专属文案（如"【沉默】降下神赐"）。

## 储物空间

### 格式
```
═══ 储物空间 ═══
玩家: 蓬莱

1. 共生噬刃×3（C级）
2. 生命药水×5
3. 铁剑
```

### 编号收回
可通过编号快速收回道具：
```
收回道具 蓬莱 1 2 3
```
将收回编号 1、2、3 的全部道具。

## 配置项

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ladder_cooldown_seconds` | int | 600 | 排行榜冷却时间（秒） |
| `query_cooldown_seconds` | int | 600 | 查询指令冷却时间（秒） |
| `ladder_display_limit` | int | 10 | 排行榜显示人数上限 |
| `init_ladder_score` | int | 1000 | 初始登神之路分 |
| `init_pilgrimage_score` | int | 100 | 初始觐见之梯分 |
| `allow_negative_scores` | bool | true | 允许录入负分 |
| `auto_backup_enabled` | bool | true | 启用自动备份 |
| `backup_retention_days` | int | 30 | 备份保留天数 |
| `prayer_trigger_groups` | list | [] | 启用祷词触发的群号列表 |
| `prayer_text_诞育` ~ `prayer_text_命运` | list | 各1条 | 16信仰祷词短语（8字） |
| `gift_daily_accept_limit` | int | 1 | 每日接受道具上限（0为不限制） |
| `inventory_easter_egg_enabled` | bool | false | 启用储物空间彩蛋 |
| `inventory_easter_egg_probability` | float | 0.05 | 彩蛋触发概率 |
