# 信仰游戏排行榜

AstrBot 群聊双积分排名插件，登神之路 + 觐见之梯双榜展示，支持弃誓/立誓系统、职业信仰体系、图片输出、批量录入、全局白名单权限管控、群名片自动识别玩家。

## 功能特性

- **双积分体系** — 登神之路 + 觐见之梯，双榜独立排名
- **职业信仰** — 6 职业 x 6 信仰，角色定制体系
- **弃誓系统** — 弃誓标记永久保留，排行榜显示(弃誓者)，可配置弃誓文本
- **立誓/设置职业** — 信仰与职业独立管理，弃誓者可通过立誓重新确立信仰
- **储物空间** — 玩家道具库系统，道具名与等级分离（固定等级 SSS/SS/S/A/B/C），支持批量录入、赐予/收回/清除道具，查询按等级排序
- **赠送道具** — 玩家间道具赠送，发送方自动从群名片识别，直接扣除等待接收方接受/拒绝（每位接收方每天限接受一次）
- **群名片识别** — 查询/储物空间/赠送道具等指令自动从群名片识别玩家身份，无需手动输入名字
- **玩家状态** — 自定义状态效果，持续指定天数，查询时显示剩余天数
- **图片输出** — 排行榜支持图片模式，渐变暗色主题，金/银/铜排名高亮
- **批量录入** — 粘贴游戏结算文本自动解析，批量更新积分（支持正负分）
- **群级设置** — 每个群可独立设置输出模式（文本/图片）
- **全局白名单** — 白名单一次添加，所有群生效
- **自动备份** — 数据自动备份，可配置保留天数
- **指令可配** — 所有指令名可通过 WebUI 配置修改
- **查询冷却** — 防刷机制，可配置冷却时间
- **直接回复** — 指令回复不经过 AI 处理，固定格式输出
- **祷词触发** — 玩家每天第一次发送命中自己命途祷词的消息时，随机获得 -2 到 +2 觐见分变化（可配置群列表、可配置回复文案）

## 职业与信仰

### 层级结构
- **命途**（6）：虚无、存在、文明、沉沦、混沌、生命
- **信仰**（16）：诞育、繁荣、死亡、污堕、腐朽、湮灭、秩序、真理、战争、混乱、痴愚、沉默、记忆、时间、欺诈、命运
- **具体职业**（96）：每个信仰 × 6 普通职业，系统自动映射到对应命途和普通职业

### 普通职业
战士 / 法师 / 牧师 / 刺客 / 猎人 / 歌者

## 群名片自动识别

部分指令通过发送者的群名片自动识别玩家身份，无需手动输入名字：

- **查询**：非诸神用户直接发送 `查询` 即可查询自己；诸神用户需指定玩家名
- **查询储物空间**：非诸神用户直接发送 `查询储物空间` 查自己；诸神用户可指定多个玩家批量查询
- **赠送道具**：发送方自动从群名片识别，格式变为 `赠送道具 <接收方名> <道具*数量>`

非诸神用户如指定其他玩家名，系统会提示"只能查询自己"。

### 名片解析规则

系统从群名片中提取所有非纯数字的词，逐个在数据库中匹配，返回第一个匹配到的玩家名。例如：
- `【命运】 织命师 蓬莱 1000 100` → 提取词：织命师、蓬莱 → 匹配数据库中的玩家名
- `【XX】 守墓人 张三 100 100` → 提取词：守墓人、张三 → 匹配数据库中的玩家名

### 具体职业自动识别

名片中的职业可以使用**具体职业**（如 酋长、织命师、守墓人等），系统会自动识别对应的**信仰**和**普通职业**。

例如名片 `【虚无】 织命师 蓬莱 1000 100`：
- 标签 `【虚无】` → 信仰 = 虚无
- `织命师` → 具体职业，映射到 信仰=虚无、职业=法师
- `蓬莱` → 玩家名

系统支持 96 个具体职业（6 信仰 × 16 阶段 × 6 普通职业），完整映射见 `specific_classes.json`。

> 天梯榜显示时统一使用普通职业（战士/法师/牧师/刺客/猎人/歌者）。

> 请确保群名片中包含与数据库一致的玩家名。

## QQ 绑定（防名片冒充）

为避免玩家通过修改群名片冒充他人，**涉及身份变更的指令**（赠送/接受/拒绝道具）强制要求玩家先绑定 QQ。
绑定后，系统通过 `event.get_sender_id()`（协议层注入、不可伪造）识别身份，不再依赖名片。

### 一对一约束
- 一个 QQ 在同一群只能绑定一个玩家
- 一个玩家只能绑定一个 QQ
- **跨群独立**：同一 QQ 在不同群可以绑定不同玩家

### 绑定途径
| 方式 | 命令示例 | 说明 |
|---|---|---|
| 录入玩家时自动绑 | `录入玩家 @张三 存在 战士 1000 100` | 自动把 @ 用户的 QQ 绑定给新玩家 |
| 诸神首绑 | `绑定QQ @张三` | 通过名片解析玩家名 → 绑定该 QQ |
| 诸神指定玩家名 | `绑定QQ 蓬莱` | 反查玩家 → 查找其在群内的名片 → 取其 QQ |
| 换绑 | `换绑QQ @新QQ用户 蓬莱` | 把玩家「蓬莱」的 QQ 换成新 @ 用户的 QQ |
| 换绑（直接给号） | `换绑QQ 蓬莱 88888888` | 同上，但直接写新 QQ 号 |

### 自动迁移
插件启动后**首次收到事件**（查询/赠送等）时，后台扫描各群未绑定 QQ 的玩家：
- 名片中**唯一匹配**到某个群成员 → 自动绑定
- 匹配歧义（0 或多个名片包含该玩家名）→ 跳过，留待手动绑定
- 仅执行一次，日志打印 `[QQMigration] 自动绑定完成：共绑定 N 个玩家`

### 未绑定玩家权限
| 指令类型 | 行为 |
|---|---|
| 只读（查询/查询储物空间） | 优先 QQ 查找；失败回退名片识别（兼容老玩家） |
| 写入（赠送/接受/拒绝道具） | **拒绝并提示**：「请让诸神使用『绑定QQ @你』完成绑定」 |

### 换绑/解绑
- **换绑**：诸神使用 `换绑QQ`，旧 QQ 自动释放，新 QQ 绑定到玩家
- **冲突保护**：若新 QQ 已绑其他玩家 → 拒绝（需先处理冲突）
- **解绑**：暂不支持自助解绑，请诸神通过「换绑到一个无人用的 QQ」变相释放

## 数据存储

- **数据库** — SQLite，位于 `AstrBot/data/astrbot_plugin_faith_ladder/ladder.db`
- **配置** — AstrBot 自动管理，位于 `AstrBot/data/config/`
- **备份** — 位于 `AstrBot/data/astrbot_plugin_faith_ladder/backups/`

### 数据库表

| 表名 | 说明 |
|------|------|
| `players` | 玩家信息（ID、群号、名字、职业、信仰、双积分、弃誓标记） |
| `player_items` | 玩家道具（道具名、等级 SSS/SS/S/A/B/C、数量） |
| `player_statuses` | 玩家状态（状态名、过期时间） |
| `score_history` | 积分变更历史记录 |
| `whitelist` | 全局白名单 |
| `active_groups` | 活跃群记录 |
| `group_settings` | 群级设置（如输出模式） |

## 安装

1. 将 `astrbot_plugin_faith_ladder` 目录上传到 AstrBot 的 `data/plugins/` 目录
2. 在 AstrBot WebUI 中启用插件
