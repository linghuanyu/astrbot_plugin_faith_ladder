# 信仰游戏排行榜

AstrBot 群聊双积分排名插件：登神之路 + 觐见之梯双榜、职业信仰体系、道具储物与赠送、弃誓/立誓、群管指令，附带一套「神明在看」的沉浸感文案（分数短句、试炼刻痕、位阶徽记、神明的赌局）。仅支持群聊。

## 功能特性

### 积分与榜单
- **双积分体系** — 登神之路 + 觐见之梯，双榜独立排名
- **榜单门槛** — 天梯榜默认只显示登神之路 ≥ 1100 分的玩家（`leaderboard_min_ladder_score`，0 为不过滤）
- **榜单缓存** — 结果缓存 `leaderboard_cache_seconds` 秒（默认 120，0 为不缓存）；任何录入/改分/改名操作都会立即失效对应群的缓存
- **批量录入** — 粘贴游戏结算文本自动解析，批量更新积分与道具（支持正负分、数量标记 `*10` / `（b）*10` 两种写法）
- **查询冷却** — 防刷机制，冷却时长可配置
- **直接回复** — 指令回复不经过 AI 处理，固定格式输出

### 玩家与道具
- **职业信仰** — 6 命途 × 16 具体信仰 × 96 具体职业，名片可自动识别
- **储物空间** — 道具名与等级分离（SSS/SS/S/A/B/C），支持赐予/收回/清除，按等级排序展示
- **赠送道具** — 玩家间赠送，发送方按 QQ 绑定鉴权（防名片冒充），接收方每日接受次数可配置，诸神代收不受限
- **玩家状态** — 自定义状态 + 持续天数，查询时显示剩余天数
- **弃誓系统** — 弃誓标记永久保留，排行榜显示 (弃誓者)，弃誓文本按信仰可配
- **群名片识别** — 查询/储物空间/赠送等指令自动从名片识别身份，职业词会被过滤

### 权限与管理
- **全局白名单** — 白名单一次添加所有群生效，可绑定具体信仰（诸神操作时显示对应神明文案）
- **管理员** — `admin_ids` 里的用户拥有全部权限，不受群角色限制
- **群访问控制** — `group_access_mode` 可选 off / blacklist / whitelist：未启用的群里插件**完全静默**（不回复、不抢事件），适合只服务指定群
- **功能开关** — 道具赠送、储物空间、祷词、排行榜、群管五块可单独关闭；诸神的录入与道具管理指令不受影响，避免管理员把自己锁死
- **状态阻断** — 状态可携带「禁止项」：`添加状态 张三 沉默 2 阻断=祷词,赠送`，被禁止的指令会回复提示
- **群管指令** — 禁言/解禁/踢人/撤回/全员禁/全员解/设置精华/移除精华（需 aiocqhttp 协议）
- **自动备份** — 每天自动备份数据库，保留天数可配置

### 沉浸感（三批改造，可用开关关掉）
- **棋局记录** — 积分变化时在数字上方加一句按信仰取的神明短句，数字下方追加「试炼刻痕」（跨整百/整千、首次登上棋盘、名次上升）；`score_flavor_enabled` 一键关掉
- **祷告分档** — 祷词随机到区间上限时走「大成功」文案池，并显示「连续 N 天被神明听见」（2/7/30 天三档）
- **位阶徽记** — 按登神之路分数分 9 阶，榜单与档案在名字前显示纯符号徽记（默认 ☽☿♀♁♂♃♄♅☉），不出现中文阶名
- **神明的赌局** — **默认关闭**（`wager_enabled`）：随机一位神明在群里抛出限时赌局，时限内「开口说话」或「献上祷词」即入局，开奖可能是兑现/嘲弄/嘴上反悔；**默认不影响真实分数**，`wager_score_enabled` 打开后只有「兑现」给赢家加分
- **状态来源** — 施加状态时写明由哪位神明降下、到哪天为止
- **祷词触发** — 玩家每天第一次发送命中自己命途的祷词时获得一次觐见分变化（默认命中 -2~+2、渎神 -2~0，区间可配）；默认只作氛围互动，`prayer_score_enabled` 打开才真实计分
- **储物空间彩蛋** — 可配置概率触发趣味消息

### 平台特性
- **合并转发** — 天梯榜、觐见榜、储物空间默认使用合并转发卡片展示
- **配置热生效** — 改 WebUI 配置后无需重载插件：祷词表、指令前缀、权限判定、榜单缓存都会跟着变
- **配置项全中文提示** — 80+ 个配置项每项都带 `hint` 说明取值与影响
- **指令名可定制显示** — `cmd_*` 影响帮助文案与祷词前缀过滤（指令本身在代码里注册，改名需改代码）

## 职业与信仰

### 层级结构
- **命途**（6）：虚无、存在、文明、沉沦、混沌、生命
- **信仰**（16）：诞育、繁荣、死亡、污堕、腐朽、湮灭、秩序、真理、战争、混乱、痴愚、沉默、记忆、时间、欺诈、命运
- **具体职业**（96）：每个信仰 × 6 普通职业，系统自动映射到对应命途和普通职业

### 普通职业
战士 / 法师 / 牧师 / 刺客 / 猎人 / 歌者

## 群名片自动识别

部分指令通过发送者的群名片自动识别玩家身份，无需手动输入名字：

- **查询**：非诸神用户直接发送 `查询` 即可查询自己；诸神用户需指定玩家名
- **查询储物空间**：非诸神用户直接发送 `查询储物空间` 查自己；诸神用户可指定多个玩家批量查询
- **赠送道具**：发送方按 QQ 绑定鉴权（需先绑定 QQ），格式为 `赠送道具 <接收方名> <道具名> [数量]`（数量也可写作 `道具*数量`）

非诸神用户指定其他玩家名不会生效，只会查询到自己的信息；指定他人需诸神权限。

### 名片解析规则

系统从群名片中提取所有非纯数字、非职业的词，逐个在数据库中匹配，返回第一个匹配到的玩家名。例如：
- `【命运】 织命师 蓬莱 1000 100` → 提取词：蓬莱 → 匹配数据库中的玩家名
- `【XX】 守墓人 张三 100 100` → 提取词：张三 → 匹配数据库中的玩家名

### 具体职业自动识别

名片中的具体职业（96个）会被自动识别并过滤，不会误匹配为玩家名。例如：
- `【湮灭】 烬灭者 蓬莱` → "烬灭者"是具体职业，被过滤；匹配"蓬莱"

## 沉浸感系统

三批改造都遵循同一条原则：**数字反馈保持原样**（`+16 → 1016` 的箭头样式一眼能看出变化），沉浸感来自"多一行"。全部可用配置关掉或替换文案。

### 棋局记录

积分变化时按信仰取一句神明视角的短句，并在下方追加试炼刻痕：

```
【秩序】把你向上推了一寸。
张三 的积分已更新
登神之路: +150 → 1150
觐见之梯: +0 → 100
—— 第 11 道刻痕。
—— 你的名字第一次被刻上棋盘。
```

刻痕共四种：跨过整百（第 N 道刻痕）、跨过整千、首次越过上榜门槛、名次上升（`—— 你越过了 N 个人。`）。扣分不会产生刻痕。关掉文字氛围：`score_flavor_enabled` = false。

### 位阶徽记

按登神之路分数分 9 阶，榜单与玩家档案在名字前显示纯符号徽记（默认从低到高 `☽ ☿ ♀ ♁ ♂ ♃ ♄ ♅ ☉`），没有中文阶名：

```
═══ 登神之路 ═══

1. ☿ 张三
   [法师] <生命>
   登神之路: 1150
```

阈值与符号都是配置项（`tier_thresholds` / `tier_marks`），可整组换成 `✦Ⅰ…` 之类；符号配得比阈值少时，多出的阶层沿用最后一个。

### 神明的赌局

**默认关闭**。打开方式：`wager_enabled` = true，并在 `wager_groups` 填群号。之后每隔 `wager_interval_minutes`（默认 30 分钟）会有一位神明现身：

> 两个实现细节：① 插件必须**收到过该群的消息**才能开局（发消息需要完整会话标识，没见过消息时拿不到），所以在刚重载、群里还没人说话的空档里会跳过一轮，等有人说话后正常开局；② 间隔判定跨重载有效（用数据库里的上次开局时间兜底），不会因为重启就立刻冒出一场。

开局时刻：按 **UTC 时间等分**对齐（间隔 30 分钟 → 每小时 :00 与 :30；间隔 60 → 整点），再叠加每群随机的延后 0~`wager_jitter_minutes` 分钟（种子含绝对时间槽，**每天同一钟点的时刻都不同**）；同一时间槽内只开一局。**静默时段**（默认本地 0~8 点，`wager_quiet_start_hour` / `wager_quiet_end_hour`）里的槽直接跳过，夜里不会开局；全新安装会立刻开第一场（夜里则等到白天）。

开局条件（自动）：总开关打开 · 群在 `wager_groups` 里 · 群**未被群访问控制排除**（黑名单/白名单模式都会生效）· 当前没有进行中的赌局 · 距上次开局已过 `wager_interval_minutes`。**也可以手动开局**：诸神/管理员在群里发送 `赌局` 即可立刻开始（不看群列表与间隔，其余条件相同；已有赌局进行中会提示还剩多久）。

```
【欺诈】眯起眼睛：「60 息内，开口说话的人——我给他一点甜头。当然，我说的是不是真话，你得自己赌。」
```

时限内完成指定动作（开局时随机要求「开口说话」或「献上祷词」——**只有在开着祷词触发的群里才会抽到「献上祷词」**，否则只会要求开口说话）即入局，时限到开奖，结果三分：**兑现 / 嘲弄 / 嘴上反悔**。默认只发文案并注明「本次结果不影响实际分数」；`wager_score_enabled` 打开后只有「兑现」会给赢家加 `wager_reward` 点觐见分。**神明可以在台词里骗你，但绝不会真的动你的分数或道具。**

每场赌局只产生两条群消息（开局 + 开奖），参与者上限 200 人，开局与入局记录在 `god_wagers` / `god_wager_entries` 两张表。16 位神明 × 5 档（开局/兑现/嘲弄/反悔/无人入局）共 80+ 句默认台词，可在 `wager_messages_*` 里整体替换（按神明覆盖用 `wager_messages_announce_欺诈` 这种形式）。

## 配置项

### 积分与榜单

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `init_ladder_score` | int | 1000 | 初始登神之路分（新玩家默认分低于榜单门槛，要先涨分才会上榜） |
| `init_pilgrimage_score` | int | 100 | 初始觐见之梯分 |
| `allow_negative_scores` | bool | true | 允许录入负分 |
| `player_name_max_length` | int | 20 | 玩家名最大长度 |
| `leaderboard_min_ladder_score` | int | 1100 | 天梯榜分数门槛（0 为不过滤） |
| `ladder_display_limit` | int | 10 | 排行榜显示人数上限 |
| `leaderboard_cache_seconds` | int | 120 | 榜单结果缓存秒数（写入立即失效；0 为不缓存） |
| `ladder_cooldown_seconds` | int | 600 | 天梯榜/觐见榜冷却（也用于批量录入与立誓/弃誓） |
| `query_cooldown_seconds` | int | 5 | 查询指令冷却 |
| `score_history_retention_days` | int | 90 | 积分历史保留天数 |

### 权限与群

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `whitelist` | list | [] | 诸神列表（每项含 id 与可选 faith） |
| `admin_ids` | list | [] | 管理员 QQ 列表 |
| `auto_whitelist_group` | string | "" | 自动白名单群号（入群自动加、退群自动移除） |
| `group_access_mode` | string | off | 群访问控制：off / blacklist / whitelist |
| `group_access_list` | list | [] | 群访问控制的群号列表 |
| `feature_gift_enabled` | bool | true | 道具赠送（赠送/接受/拒绝） |
| `feature_inventory_enabled` | bool | true | 储物空间查询 |
| `feature_prayer_enabled` | bool | true | 祷词触发 |
| `feature_scoreboard_enabled` | bool | true | 排行榜（天梯榜/觐见榜） |
| `feature_qq_admin_enabled` | bool | true | 群管指令（8 条） |

### 道具与状态

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `gift_daily_accept_limit` | int | 1 | 每日接受道具上限（0 为不限制；诸神代收不受限） |
| `inventory_easter_egg_enabled` | bool | false | 启用储物空间彩蛋 |
| `inventory_easter_egg_probability` | float | 0.05 | 彩蛋触发概率（0~1） |
| `inventory_easter_egg_messages` | list | 4 条内置 | 彩蛋文案（留空则该功能静默失效） |

### 祷词与文案

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `prayer_trigger_groups` | list | [] | 启用祷词触发的群号列表（留空不启用） |
| `prayer_score_enabled` | bool | false | 祷词是否真实改分（关闭时只展示结果） |
| `prayer_score_min` / `prayer_score_max` | int | -2 / 2 | 命中自己信仰时的分值区间 |
| `prayer_blasphemy_score_min` / `prayer_blasphemy_score_max` | int | -2 / 0 | 渎神（信仰不匹配）时的分值区间 |
| `prayer_text_诞育` ~ `prayer_text_命运` | list | 各 1 条 | 16 位信仰的祷词短语（每条恰好 8 个汉字） |
| `prayer_trigger_messages_positive` / `_negative` / `_neutral` / `_mismatch` / `_crit` | list | [] | 祷词回复文案池（留空用内置；按信仰可加 `_信仰名` 后缀，需手改配置） |
| `oath_text_诞育` ~ `oath_text_命运` | string | 各 1 条 | 16 位信仰的弃誓文本（可用 `{name}` 占位符） |
| `cmd_ladder` 等 12 个 `cmd_*` | string | 中文指令名 | 影响帮助文案与祷词前缀过滤（改指令名需改代码） |

### 沉浸感

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `score_flavor_enabled` | bool | true | 积分变化时是否加一句神明视角短句 |
| `score_flavor_messages` | list | [] | 自定义分数短句池（留空用内置；按信仰可加 `_信仰名` 后缀） |
| `tier_thresholds` | list | 9 个阈值 | 位阶划分（登神之路分数，升序） |
| `tier_marks` | list | 9 个符号 | 位阶徽记（与阈值一一对应，纯符号） |
| `wager_enabled` | bool | false | 启用「神明的赌局」 |
| `wager_groups` | list | [] | 启用赌局的群号列表 |
| `wager_interval_minutes` | int | 30 | 开局间隔（按 UTC 时间等分，如 30 → 每小时 :00 / :30） |
| `wager_jitter_minutes` | int | 5 | 在等分点基础上随机延后 0~N 分钟（每群固定、重启不变） |
| `wager_quiet_start_hour` | int | 0 | 静默时段起点（本地时间）；与该时段内不开局 |
| `wager_quiet_end_hour` | int | 8 | 静默时段终点（本地时间，不含该点）；两端相同表示不静默 |
| `wager_duration_seconds` | int | 60 | 入局窗口长度（最小 5 秒） |
| `wager_score_enabled` | bool | false | 赌局是否真的改分（仅「兑现」给分） |
| `wager_reward` | int | 3 | 兑现时给赢家的觐见分 |
| `wager_messages_announce` / `_win` / `_lose` / `_tease` / `_none` | list | [] | 赌局台词池（留空用内置；按神明可用 `_欺诈` 后缀） |
